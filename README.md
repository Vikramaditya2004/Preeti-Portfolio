## 🌐 About The Project

**Preeti Careers** is a modern single-page recruitment and job opportunity website created for **Preeti Kumari, Hiring Manager**.

The website is designed to provide a professional platform for showcasing available career opportunities, connecting job seekers with hiring information, and presenting the hiring manager's profile.

The interface focuses on a clean, modern, responsive experience that works across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📟 Tablet

---

## ✨ Features

### 🏠 Modern Landing Page
A professional hero section introducing the recruitment platform and available opportunities.

### 💼 Featured Job Opportunities
Displays available positions with important information such as:

- Job title
- Company
- Location
- Salary range
- Job category
- Application option

### 🏢 Job Categories
Organized career categories make it easier for visitors to understand the types of opportunities available.

Categories include:

- 💻 Development
- 📈 Sales & Marketing
- 🎨 Design
- 👥 Human Resources
- 🎧 Customer Support
- 💰 Finance

### 👩‍💼 Hiring Manager Profile

Dedicated section for:

**Preeti Kumari**  
*Hiring Manager*

The section provides information about the person responsible for recruitment and talent acquisition.

### 📩 Job Application Interface

Candidates can interact with job opportunities through the application's interface.

### 📱 Responsive Navigation

The website includes a responsive navigation system with mobile menu support for smaller screens.

### 🎨 Modern UI

The interface uses:

- Clean cards
- Rounded components
- Modern typography
- Professional color palette
- Hover effects
- Smooth animations
- Responsive layouts

### ⚡ Interactive JavaScript

JavaScript is used for interactive website functionality including:

- Mobile navigation
- Job interactions
- Application modal
- Toast notifications
- Scroll animations
- Smooth navigation
